# Python Modules

This repository documents my progression through the Python modules at 42.

It is a record of what I learned and a resource for other people following a similar path. The focus is on how the ideas and code develop from one module to the next, not only on finished exercise solutions.

## 🌱 About this repository

This is the public educational version of my work. It does not always match the original submission structure.

```text
exercise solutions
        ↓
learning progression
        ↓
documented + commented code
```

Repetitive exercises may be reorganized, related examples may be brought together, and comments or small adjustments may be added for clarity. The aim is to preserve and explain the learning progression rather than reproduce every submission exactly.

## 🗺️ Learning path

Each directory represents one stage of the learning path. Its README contains the educational notes for that module.

| Module | Focus |
|---|---|
| [Module 0](module0/) | Python fundamentals: functions, data, control flow, iteration, recursion, strings, and type hints |
| [Module 1](module1/) | Object-oriented programming: classes, state, encapsulation, inheritance, and related methods |

The modules are intended to be read in order. Start with a module README for an overview, then explore its code and examples as they are added. New modules will extend this list while the root README remains a short guide to the repository.
